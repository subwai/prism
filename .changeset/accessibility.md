Works better with screen readers and the keyboard. F2, or File > Rename…, renames the selected photo, video or folder, and Shift-F10, or the menu key, opens its right-click menu just below it. Going to another folder or view from the toolbar keeps focus in the grid. Screen readers hear each item's position in the folder, whether it is a folder or a video, which photo the viewer moves to, and the video's time as you scrub.

Screen readers announce each button's keyboard shortcut. With Increase Contrast on, faint labels, lines and fills are stronger; with Reduce Transparency on, the window's content is opaque; and in Windows high contrast themes, what is selected or pressed is outlined.
